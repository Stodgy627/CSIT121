W3C recommends wide deployment as a web standard because it has committments from Web Share API group members to make implementation royalty-free.

Privacy: Web Share API cannot be used by a website to learn which share targets are available or which target a user chose, which prevents fingerprinting or leaking info about the user's device or sharing preferences.

Simplicity for Developers: One API call replaces maintaining platform-specific share functions.

Enhancement: Layers on top of existing UX, if the browser doesn't support Web Share, you fall back to a sharing mechanism that is supported.
