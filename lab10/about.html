Sharing Files:

  • navigator.share(data): triggers share dialog, invokes the native sharing mechanism of the underlying OS. Requires transient acitvation, must be triggered through something like a button click.
  • navigator.canShare(data): validates if data is "shareable" before passing it to navigator.share() method

Sharing links and text:

To share links and text, you can use the share() method. The object must contain a title, text, url, or files or the browser will throw a TypeError. Therefore you can share a text without a URL or vice versa.

The ShareData dictionary has for optional members: files (what is being shared), text (body of the message), title (document title), and url (URL of resource/file being shared).


Limitations:

  • Can only be used on sites that are accessed through HTTPS
  • The defualt allowlist of 'self' makes Web Share API available in first-party contexts by default. To allow for third-party use you must use the iframe's allow="web-share" attribute.
  • Can only share URLs, text, or files
  • Can only be invoked in response to a user action such as a click.
