What is Web Share API?

The Web Share API is an API designed for sharing text, links and other content to a destination the user defines. The available share targets are determined by the user, and could be anything like apps, websites, or contacts.

Web Share API utilizes the sharing mechanisms of the underlying OS, therefore sharing can be done through the system clipboard, email, contacts, or messaging apps.

Many browsers currently have full support for Web API examples include Chrome, Edge, Safari, and Samsung Internet. Although, Firefox does not support Web Share API.
