Lessons Learned Reflection

This project was the most time consuming lab I've done since lab 8 I believe. While time consuming, I liked acting as if I was creating a real website for a company, it allowed me to get creative. I really enjoyed doing the cafe theme too because I've been going to alot of cafes recently. I thought I would struggle a lot with this online course, but honestly I learned a lot throughout these labs and while I said this project was time consuming, without all the experience of doing the other labs this would have taken me ages to create.

What I learned in this course is that HTML isn't that hard of a language to learn. On the other hand, with HTML comes a lot of things I didn't think about before like making sure that your website is accessible to everyone and every device. I never thought that you could face fines for not having accessibility either. While I said HTML is relatively easy to learn, the hard and also fun part of creating websites is styling your page with CSS and other stuff like Javascript.
